## 本次掌握内容

- `input()` 接收输入，返回 `str`。
- `print()` 输出内容到终端。
- `int()` 和 `float()` 用于类型转换。
- `=` 是赋值，`==` 是相等判断。
- `** 2` 表示平方。
- `if / elif / else` 用于条件判断。
- Python 使用缩进表示代码块。

## 典型错误和修正

- BMI 公式不能写成 `height * 2`，应写成 `height ** 2`。
- `else` 后面不能写条件；需要条件时使用 `elif`。
- 数学计算前要把 `input()` 得到的字符串转换成数字。
