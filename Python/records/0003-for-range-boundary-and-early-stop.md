# 掌握 for 的次数边界与提前停止

用户已经能用 `range(1, max_attempts + 1)` 准确表达从第 1 次到第 8 次的有限循环，并在猜中时用 `break` 提前停止。这表明后续课程可以把 `for` 的不含终止值边界、循环变量和循环内状态计算作为已掌握基础。

## Evidence

- `guess_number.py` 用 `attempt` 表示当前次数，并用 `max_attempts - attempt` 正确计算剩余机会。
- 输入 `10`、`20`、`30` 时，程序在第 3 次猜中后停止，没有继续请求输入。
- 连续输入 8 个错误数字时，程序完整执行 8 轮，并在循环结束后显示机会已用完和正确答案。

## Implications

第四课可以把条件分支抽进函数，继续训练“输入数据 → 处理 → 返回结果”，不需要重新讲解 `for` 的基本结构。
