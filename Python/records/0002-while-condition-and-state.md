# 掌握 while 的停止条件与状态更新

用户已经能用 `while guess != secret` 让猜数字程序持续接收输入，更新 `guess`，并只在猜中时退出；同时能用 `attempts = attempts + 1` 正确累计次数。这表明后续课程可以把“条件检查 → 执行循环体 → 更新状态 → 再次检查”作为已掌握基础。

## Evidence

- 实际运行中，程序能在猜小和猜大后继续，并在输入 `7` 后停止。
- 成功修正了 `while guess < secret` 导致猜大时错误退出的问题。
- 成功修正了 `attempts = attempts` 导致计数始终为零的问题。
- 用户能独立解释：输入 `9` 时 `guess != secret` 为真，所以继续；输入 `7` 时条件为假，所以结束。
