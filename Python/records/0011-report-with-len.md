# 掌握用 len 和 count 生成测试报告

用户已经能用 `len(results)` 统计结果列表总长度，并结合 `results.count("猜中了")` 生成“共测试几次、猜中几次”的报告。这说明用户能把列表处理结果进一步整理成面向人阅读的输出。

## Evidence

- 能预测 `len(results)` 与 `results.count("太小了")` 的区别：前者数全部元素，后者只数目标值出现次数。
- 编写并运行 `report_results.py`，通过 `build_report(results)` 返回报告字符串。
- 曾出现 `[[...], [...], [...]]`，随后修正为每轮追加本轮 `result`，得到正确的结果列表。
- 将输入迁移到 `[10, 20, 25, 28]` 后得到四个“太小了”，并输出“共测试 4 次，猜中 0 次。这组测试里没有猜中”。

## Implications

下一课可以开始引入字典 `dict`，把“总次数”“猜中次数”“建议”组织成带名字的数据，为后续理解 JSON 和 AI API 返回结果做准备。教学时继续区分“整个列表”“列表里的一个元素”和“报告字符串”。
