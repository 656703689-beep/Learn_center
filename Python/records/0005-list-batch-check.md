# 掌握列表与逐个批量处理

用户已经能用列表保存多个测试值，并用 `for` 按列表顺序逐个取出当前值，再把当前值交给函数处理。这表明用户开始从“处理一个输入”过渡到“批量处理一组数据”，这是后续 AI 数据处理练习的基础。

## Evidence

- 能预测 `guesses = [10, 30, 40]` 配合 `for guess in guesses` 会依次打印 `10`、`30`、`40`。
- 能预测列表顺序改成 `[40, 10, 30]` 后，循环输出也按同样顺序变为 `40`、`10`、`30`。
- 编写并运行 `batch_guesses.py`，把 `10`、`30`、`40`、`25` 逐个传给 `compare_guess(guess, secret)`，得到四行正确结果。
- 修正了对 `print(guess, result)` 输出格式的理解：逗号打印会用空格分隔，不会自动显示括号。

## Implications

下一课可以继续扩展列表：先保持“逐个处理”的主线，再引入把结果保存回新列表或统计数量。教学时仍需区分整个列表 `guesses` 和当前元素 `guess`，并继续复习函数返回值的数据流。
