# 掌握函数参数与返回值的数据流

用户已经能定义并调用带参数的函数，准确追踪“实参 → 参数 → 条件分支 → 返回值 → 接收变量”的数据流，并理解 `if` 负责选择分支、`return` 负责把结果交回调用处。这表明后续课程可以把函数作为已掌握的程序组织单位。

## Evidence

- 独立完成 `function_lab.py`，输入 `20`、`30`、`40` 时分别得到“太小了”“猜中了”“太大了”。
- 能说明调用 `compare_guess(20, 30)` 时，`guess` 接收 `20`，`secret` 接收 `30`。
- 在迁移题 `answer = double(6)` 中，准确识别 `number` 是参数、`6` 是实参、`answer` 最终为 `12`。
- 修正了把分支选择与返回值来源混为一谈的理解，能够区分 `print()` 是显示内容，而 `return` 是交回可继续使用的值。

## Implications

第五课可以把“函数处理一个值”扩展为“列表保存多个值，循环逐个交给函数处理”，同时穿插复习 `for`、条件判断和返回值。
