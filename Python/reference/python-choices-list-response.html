Reference / choices list

读取 choices 里的 AI 回复

choices 是 list；先用 [0] 取第一项，再从里面的 dict 继续取值。

固定模板

import json

response_text = '{"choices": [{"message": {"content": "已经猜中过，测试通过"}}]}'

response = json.loads(response_text)

print(response["choices"][0]["message"]["content"])

等价拆开写法：

choices = response["choices"]
first_choice = choices[0]
message = first_choice["message"]
print(message["content"])

每一步拿到什么

表达式结果取值规则
response外层 dict用 key
response["choices"]list下一步用 index
response["choices"][0]第一份回复 dict下一步用 key
response["choices"][0]["message"]内层 message dict下一步用 key
response["choices"][0]["message"]["content"]回复文字最终 value

常见检查点

现象检查
KeyError: 0你可能对 dict 用了数字 key。确认当前对象是不是 list。
IndexError: list index out of rangechoices 可能是空列表，没有第 0 项。
KeyError: 'message'第 0 项里可能没有 "message" 这个 key。
链式取值看不懂拆开写：choices、first_choice、message。

一句话记忆

response["choices"][0]["message"]["content"]：key 取 choices，数字 0 取第一项，再用 key 取 message 和 content。
