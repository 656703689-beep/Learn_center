Reference / loop through choices

逐条读取 choices

从 choices 列表逐个取出 choice 字典，再读里面的文字。

读取模板

用于本课模拟结构：choices 是列表，每一项含有 message 字典和其中的 content 字段。

import json

response_text = '{"choices": [{"message": {"content": "先检查输入"}}, {"message": {"content": "再核对结果"}}]}'
response = json.loads(response_text)

choices = response["choices"]
for choice in choices:
    message = choice["message"]
    print(message["content"])

熟悉后可以合并最后四行：

for choice in response["choices"]:
    print(choice["message"]["content"])

变量与数据的对应关系

表达式在本例中是什么
response["choices"]包含全部回复的 list
choice当前这一份回复的 dict
choice["message"]当前回复里的 message 字典
message["content"]当前回复的文字 value

依据：Python 官方 for 教程 · 官方字典教程 · 官方 json.loads 文档。

写完检查三处

  • for 后面遍历的是 choices 列表；每轮用 choice 读取当前元素。
  • message = … 和 print(…) 都缩进在循环里，才会逐条输出。
  • 循环里读 choice["message"]；如果每轮都读 choices[0]，就会重复第一条。
复习时再想：choices 是 [] 会怎样？

这个循环执行零轮，不输出回复。直接读取 choices[0] 则会触发 IndexError。这只说明空列表的行为，其他字段仍需符合示例结构。
