读取模拟 AI 回复

外部系统给的是 JSON 字符串；Python 先用 json.loads() 解析，再按 key 读取字段。

固定模板

import json

response_text = '{"reply": "已经收到报告", "score": 2}'

response = json.loads(response_text)

print(response["reply"])
print(response["score"])
变量含义
response_text模拟外部 AI API 返回的 JSON 字符串。
response解析后的 Python dict。
response["reply"]从 dict 里读取 AI 回复文字。

依据：Python 官方 json 文档。

数据流

文本response_text
转换json.loads
字典response
字段response["reply"]

常见检查点

现象检查
NameError: name 'json' is not defined顶部是否写了 import json。
JSONDecodeErrorJSON 字符串里的 key 和字符串 value 是否用了双引号。
KeyError: 'reply'解析后的 dict 里是否真的有 "reply" 这个 key。
直接对文本取 key 出错先确认是否已经执行 response = json.loads(response_text)。
