Core tools

五个最先用到的工具

写法 作用 最小例子
input() 显示提示、等待键盘输入，返回 str name = input("名字：")
print() 把值输出到终端 print(name)
int() 把合适的值转换为整数 age = int("18")
float() 把合适的值转换为小数 height = float("1.72")
type() 查看一个值当前的类型 print(type(height))

四种基础类型

str 文本

"AI"、"45"。引号中的数字仍是文本。

int 整数

45、-2。没有小数部分。

float 小数

36.5、1.72。适合温度、身高等量。

bool 真或假

True、False。常用于判断条件。

格式化输出

name = "小智"
minutes = 45
print(f"{name} 今天学习 {minutes} 分钟")

f 让大括号中的变量值进入文本。

Structure

变量名与缩进

变量名

推荐小写英文单词，用下划线分隔：study_minutes。不能含空格、不能以数字开头，也不能前后拼写不一致。

缩进

冒号后的代码块通常缩进 4 个空格；同一代码块必须对齐。缩进决定代码属于哪个判断或循环。

if minutes >= 30:
    print("完成半小时练习")
    print("继续保持")

print("这个输出不受 if 控制")
Debug

读报错：先看最后一行

最后一行 通常表示 第一反应
SyntaxError 语法结构不合法 检查箭头附近，也检查前一个引号、括号或冒号
IndentationError 缺少缩进或对齐不一致 检查冒号后的行，统一为 4 个空格
NameError 使用了不存在的变量名 检查是否赋值、是否拼错、大小写是否一致
TypeError 操作与值的类型不匹配 用 type() 检查参与运算的值
ValueError 类型转换的内容不合适 确认输入真的是数字，例如不要执行 int("AI")
报错不是判分，是定位报告 从最后一行得到错误类型，再根据文件名和行号回到代码。一次只修改一个原因，然后重新运行。
