Reference / join contents

合并多条 content

用 分隔符.join(列表) 把字符串列表合成一段文本。

完整模板

import json

response_text = '{"choices": [{"message": {"role": "assistant", "content": "先检查输入"}}, {"message": {"role": "assistant", "content": "再检查条件"}}, {"message": {"role": "assistant", "content": "最后整理回答"}}]}'
response = json.loads(response_text)

contents = []

for choice in response["choices"]:
    message = choice["message"]
    content = message["content"]
    contents.append(content)

final_text = "\n".join(contents)

print(final_text)

常用分隔符

代码用途输出形状
"\n".join(contents)整理步骤、日志、回复块每条一行
"，".join(contents)合成一句中文逗号分隔的一行
"".join(contents)直接贴合中间没有分隔

写完检查三处

  • contents 里必须都是字符串。
  • join() 前面的字符串是分隔符。
  • 要一条回复一行，分隔符用 "\n"。

依据：Python 官方 str.join() · Python 官方 list.append() · 官方 json.loads 文档。
