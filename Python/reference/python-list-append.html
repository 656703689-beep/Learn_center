Reference / append

先收集，再使用

当程序需要保留每一轮的结果时，先创建空列表，再在循环里 append()。

核心结构

results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

print(results)
写法含义
results = []创建一个空列表，准备保存结果。
result本轮函数返回的一个结果。
results.append(result)把本轮结果加到 results 的末尾。
print(results)循环结束后，一次显示整个结果列表。

依据：Python 官方列表方法。

逐轮变化

时刻resultresults
循环前还没有[]

第 3 轮后"太大了"["太小了", "猜中了", "太大了"]

常见检查点

现象检查
只保存了最后一个结果确认使用的是 append()，不是每轮重新写 results = [result]。
结果列表是空的确认 results.append(result) 缩进在 for 里面。
顺序不对检查输入列表 guesses 的顺序；append() 按添加顺序放到末尾。
