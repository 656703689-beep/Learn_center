总数和命中数

len() 数列表总长度，count() 数某个值出现几次。

核心结构

total_count = len(results)
hit_count = results.count("猜中了")

report = f"共测试 {total_count} 次，猜中 {hit_count} 次。"
写法含义
len(results)统计 results 列表里一共有几个元素。
results.count("猜中了")统计 "猜中了" 在列表中出现几次。
total_count总测试次数。
hit_count猜中次数。

依据：Python 官方 len() 文档。

len 和 count 的区别

列表表达式结果
["太小了", "猜中了", "太大了"]len(results)3
["太小了", "猜中了", "太大了"]results.count("猜中了")1
["太小了", "太小了"]results.count("猜中了")0

现象检查
