收集多条 content

先创建空列表，再在循环里把当前文字追加进去。

读取模板

import json

response_text = '{"choices": [{"message": {"role": "assistant", "content": "第一步检查输入"}}, {"message": {"role": "assistant", "content": "第二步检查条件"}}]}'
response = json.loads(response_text)

contents = []

for choice in response["choices"]:
    message = choice["message"]
    content = message["content"]
    contents.append(content)

print(contents)

三步记忆

步骤代码作用
准备contents = []创建空列表，用来保存结果
读取content = message["content"]拿到当前这一条文字
保存contents.append(content)把当前文字追加到列表末尾

写完检查三处

  • contents = [] 写在循环前，只创建一次。
  • contents.append(content) 缩进在循环里，每条回复执行一次。
  • 最后再 print(contents)，看列表里是否收集到了所有文字。

依据：Python 官方 list.append() · Python 官方 for 教程 · 官方 json.loads 文档。

如果输出仍是一条一条文字，说明你在显示；如果输出是带方括号的列表，说明你已经保存了结果。
