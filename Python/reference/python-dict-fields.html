多字段报告

dict 可以同时保存多个 key-value；字段越完整，后续分析越方便。

核心结构

report = {
    "total": total_count,
    "small": small_count,
    "big": big_count,
    "hits": hit_count,
    "summary": summary
}
keyvalue 来源含义
"total"len(results)总测试次数。
"small"results.count("太小了")偏小次数。
"big"results.count("太大了")偏大次数。
"hits"results.count("猜中了")猜中次数。
"summary"suggest_from_counts(...)总结建议。

依据：Python 官方教程：字典。

按字段读取

print(report["small"])
print(report["big"])
print(report["summary"])
读法 report["small"] 读作：从 report 里取 key 为 "small" 的 value。

常见检查点

现象检查
KeyError: 'small'return {...} 里是否真的写了 "small": small_count。
偏大和偏小数字反了检查 small_count 是否数 "太小了"，big_count 是否数 "太大了"。
总结不符合统计检查传给 suggest_from_counts 的三个参数顺序。
