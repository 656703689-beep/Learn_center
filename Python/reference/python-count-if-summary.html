Reference / count + if

用数字做总结

先用 count() 得到次数，再用 if 根据次数选择输出。

核心结构

hit_count = results.count("猜中了")

if hit_count > 0:
    print("这组测试里猜中过")
else:
    print("这组测试里没有猜中")
写法含义
results.count("猜中了")数 "猜中了" 在结果列表里出现几次。
hit_count保存猜中次数的整数。
hit_count > 0判断是否至少猜中过一次。
else当前面条件为假时执行。

依据：Python 官方 if 语句与列表 count() 方法。

两种情况

hit_count条件输出
11 > 0 为真这组测试里猜中过
00 > 0 为假这组测试里没有猜中

常见检查点

现象检查
总是走 else检查 results.count("猜中了") 里的字符串是否和函数返回值完全一致。
报缩进错误if 与 else 对齐；它们下面的 print 多缩进一级。
不知道 hit_count 是什么先单独 print(hit_count)，确认它是一个数字。
