Reference / list parameter

函数也能处理一整组

把列表作为实参传给函数，函数内部可以统计、判断，并 return 一句总结。

核心结构

def suggest_from_results(results):
    hit_count = results.count("猜中了")

    if hit_count > 0:
        return "已经猜中过，测试通过"
    else:
        return "这组测试里没有猜中"


summary = suggest_from_results(["太小了", "猜中了"])
print(summary)
位置含义
results 参数函数内部接收的一整个列表。
results.count(...)在这个列表里统计某个结果出现几次。
return "..."把一句总结交回调用处。
summary接住函数返回值的变量。

依据：Python 官方函数定义与return 语句。
