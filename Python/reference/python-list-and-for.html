Reference / list and for

整组与单个

沿着每一轮看数据：列表里有什么，本轮取出什么，函数交回什么。

三行核心结构

guesses = [10, 30, 40]
for guess in guesses:
    print(guess)
写法含义
[10, 30, 40]列表（list）：方括号内按顺序放置多个值，用英文逗号分隔。
10、30、40元素（element）：列表中的各个值。
guesses引用整个列表的变量名。
guess循环变量：在本例中，每轮依次接到一个整数。

变量名由程序员选择。for number in guesses: 也可以，循环体需相应使用 number。

依据：列表、for 语句。

逐个调用函数

先定义第四课的 compare_guess，再执行：

guesses = [10, 30, 40]
secret = 30

for guess in guesses:
    result = compare_guess(guess, secret)
    print(f"{guess}：{result}")
轮次本轮调用result 接到
第 1 轮compare_guess(10, 30)"太小了"
第 2 轮compare_guess(30, 30)"猜中了"
第 3 轮compare_guess(40, 30)"太大了"

return 结束当前函数调用，主程序随后继续执行。本例循环中没有提前退出的语句，因此每个元素都会被处理。

依据：return 语句。

常见困惑，按位置检查

看到的情况检查什么
只显示最后一个结果检查 print 是否缩进在 for 内；每轮工作要放进循环体。
提示函数名称不存在确认当前脚本先定义了 compare_guess，然后才调用。
把整个列表交给比较函数后报错本课函数需要两个数字；循环内应传入 guess，而非整个 guesses。
误以为会输出 0、1、2for guess in guesses 直接取元素，本例取到的是 10、30、40。
补充自测：如果列表是 [] 呢？

[] 是空列表，没有元素可取，因此这个 for 的循环体执行零次。循环后的代码仍会执行；不要在循环后依赖一个只在循环内赋值的变量。
