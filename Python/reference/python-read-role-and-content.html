Reference / role and content

读取 role 和 content

每轮先拿到当前 choice，再取出 message 字典，最后读取两个字段。

读取模板

import json

response_text = '{"choices": [{"message": {"role": "assistant", "content": "先打印输入"}}, {"message": {"role": "assistant", "content": "再检查条件"}}]}'
response = json.loads(response_text)

choices = response["choices"]
for choice in choices:
    message = choice["message"]
    print("角色：", message["role"])
    print("内容：", message["content"])

每层数据

表达式职责
response最外层字典，直接保存 choices
response["choices"]全部回复组成的列表
choice当前这一份回复字典
choice["message"]当前回复里的消息字典
message["role"]当前消息的角色
message["content"]当前消息的文字内容

写完检查三处

  • 只写一个 for 循环；不要为 role 再写第二个循环。
  • message = choice["message"] 写在循环里面，因为每轮的 choice 会变。
  • 如果出现 KeyError，先检查字段名拼写和当前层级是否正确。
