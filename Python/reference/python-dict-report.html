带名字的数据

dict 用 key-value 保存数据：key 是名字，value 是对应的值。

核心结构

report = {
    "total": 3,
    "hits": 1,
    "summary": "已经猜中过，测试通过"
}
部分角色含义
"total"key数据的名字：总测试次数。
3value这个名字对应的值。
reportdict把多个 key-value 放在一起的数据盒子。

依据：Python 官方教程：字典。

按 key 取 value

print(report["total"])
print(report["hits"])
print(report["summary"])

1
