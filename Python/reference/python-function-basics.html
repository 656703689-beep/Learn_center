Reference / function basics

数据进去，结果回来

函数把一段工作命名。调用时把数据交给参数，函数体处理数据，return 再把结果交回调用处。

arguments 20, 30
parameters guess, secret
body 比较大小
return "太小了"
Core shape

最小结构

def 函数名(参数):
    处理数据
    return 结果


变量 = 函数名(实参)

对应猜数字比较：

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


message = compare_guess(20, 30)
定义不等于调用 执行 def 会创建函数并绑定函数名；函数体要等到 compare_guess(...) 被调用时才执行。
Trace

一次调用的四步追踪

步骤 compare_guess(20, 30) 检查问题
1. 实参进入 20、30 调用时给了哪些值？
2. 参数接收 guess = 20、secret = 30 每个参数接到哪个值？
3. 函数体处理 20 < 30 为 True 走进哪个分支？
4. 返回结果 "太小了" 调用表达式最终变成什么值？
Vocabulary

四个词不要混

术语 例子 记法
定义 definition def compare_guess(...): 写下这台“小机器”如何工作
参数 parameter guess、secret 定义里接收数据的名字
实参 argument 20、30 这次调用实际交进去的值
调用 call compare_guess(20, 30) 让函数体真正执行一次
Return

return 与 print 的分工

return value

结束当前调用，把 value 交回调用位置；这个值还能被保存或继续处理。

print(value)

把 value 显示到终端；它解决的是“让人看见”，不是“把结果交回”。

result = compare_guess(20, 30)  # return 的值进入 result
print(result)                   # 再把 result 显示出来
Debug

四个高频问题

症状 常见原因 检查位置
IndentationError 函数体没有缩进 def 下一行开始缩进 4 个空格
NameError 在定义函数之前就调用它 先执行 def，后写调用
TypeError 调用时少给或多给了实参 对照参数数量与调用中的值
没有显示结果 只定义未调用，或返回后没有打印 分别检查“调用”和 print()
