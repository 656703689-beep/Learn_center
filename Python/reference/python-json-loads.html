Reference / json.loads

JSON 转回 Python 数据

json.loads(json_text) 把 JSON 字符串转回 Python 的 dict 或 list。

核心结构

import json

data = json.loads(json_text)
部分含义
json_textJSON 格式的字符串。
json.loads(json_text)把 JSON 字符串转回 Python 数据。
data["name"]如果转回的是 dict，就可以按 key 取值。
for report in reports如果转回的是 list，就可以循环逐个取元素。

依据：Python 官方 json 文档。

dumps 和 loads 的方向

函数方向结果
json.dumps(data)Python 数据 → JSON 字符串str
json.loads(json_text)JSON 字符串 → Python 数据dict 或 list
记忆法 dumps 像“倒出去”；loads 像“装进来”。

常见检查点

现象检查
NameError: name 'json' is not defined检查顶部是否写了 import json。
JSONDecodeError检查 JSON 字符串是否是合法 JSON：key 和字符串必须用双引号。
无法用 key 取值先确认 json.loads() 后得到的是 dict，还是 list。
