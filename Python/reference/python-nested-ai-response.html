Reference / nested response

读取嵌套 AI 回复

当 dict 的 value 还是一个 dict 时，要一层一层取值。

固定模板

import json

response_text = '{"message": {"content": "已经猜中过，测试通过"}}'

response = json.loads(response_text)

print(response["message"]["content"])

等价拆开写法：

message = response["message"]
print(message["content"])

每一层是什么

表达式结果
response外层 Python dict。
response["message"]内层 Python dict。
response["message"]["content"]内层 dict 里的回复文字。
response["usage"]["total_tokens"]内层 usage 字典里的数字。

依据：Python 官方字典教程 与 Python 官方 json 文档。

常见检查点

现象检查
KeyError: 'content'检查 content 是否在内层 message 里，而不是直接在外层 response 里。
KeyError: 'message'检查 JSON 文本里是否真的有 "message" 这个 key。
TypeError检查你当前取到的是 dict、list 还是字符串。
链式取值看不懂先拆成两行：message = response["message"]，再 message["content"]。

一句话记忆

response["message"]["content"] 的意思是：先进 message，再取 content。
