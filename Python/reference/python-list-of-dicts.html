Reference / list of dicts

一串带字段的数据

list of dicts 的意思是：外层是列表，列表里的每个元素都是字典。

核心结构

reports = [
    {"name": "第一组", "hits": 1},
    {"name": "第二组", "hits": 0}
]
部分类型作用
reportslist保存多份报告。
{"name": "第一组", ...}dict保存一份报告里的多个字段。
"name"key字段名。
"第一组"value字段值。

依据：Python 官方教程：列表和 Python 官方教程：字典。

循环读取每份报告

for report in reports:
    print(report["name"])
    print(report["hits"])
读法 for report in reports：每轮从 reports 这个列表里取出一份 dict，临时叫它 report。

常见检查点

现象检查
TypeError确认 reports 里面放的是 dict，不是一句字符串。
KeyError确认每个 dict 里都有你要取的 key，例如 "summary"。
只打印了一组检查 reports = [report1, report2, report3] 是否包含所有报告。
