Reference / json.dumps

Python 数据转 JSON

json.dumps(data, ensure_ascii=False) 把 Python 的 dict 或 list 转成 JSON 字符串。

核心结构

import json

json_text = json.dumps(data, ensure_ascii=False)
部分含义
import json使用 Python 标准库里的 json 模块。
json.dumps(data)把 Python 数据转成 JSON 格式字符串。
ensure_ascii=False让中文直接显示，不强制转成 \u...。
json_text保存转换后的字符串。

依据：Python 官方 json 文档。

Python dict 和 JSON 字符串的外观区别

类型例子
Python dict 打印{'total_groups': 3, 'passed_groups': 2}
JSON 字符串内容{"total_groups": 3, "passed_groups": 2}
检查问题 看到输出时先问：这是 Python 自己的数据，还是已经转成 JSON 文本？

常见检查点

现象检查
NameError: name 'json' is not defined检查文件顶部是否写了 import json。
中文变成 \u...检查是否写了 ensure_ascii=False。
输出仍是单引号你可能打印的是原始 dict，不是 json_text。
