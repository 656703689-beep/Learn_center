Reference / if elif else

从上往下，命中一个

多个条件连在一起时，Python 从上往下检查，执行第一个为真的分支。

核心结构

if hit_count > 0:
    print("已经猜中过，测试通过")
elif small_count > big_count:
    print("整体偏小，可以试大一点")
elif big_count > small_count:
    print("整体偏大，可以试小一点")
else:
    print("还没猜中，但偏小和偏大一样多")
位置作用
if先检查最重要的情况：是否猜中过。
elif前面不成立时，继续检查另一种情况。
else前面的条件都不成立时执行。
缩进代码只有所属条件命中时才执行。

依据：Python 官方 if 语句。
