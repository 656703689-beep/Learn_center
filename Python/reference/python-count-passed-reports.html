Reference / count passed reports

统计通过组数

循环多份报告，检查每份报告的 "hits"。只要 hits > 0，这组就算通过。

核心结构

passed_count = 0

for report in reports:
    if report["hits"] > 0:
        passed_count = passed_count + 1

print("通过组数：", passed_count)
部分含义
passed_count = 0计数器，从 0 开始。
for report in reports逐份取出报告字典。
report["hits"] > 0判断这一组是否至少猜中过一次。
passed_count + 1遇到通过组，就累计一次。

依据：Python 官方教程：for 语句、if 语句和 字典。

手动追踪

report["hits"]是否通过passed_count
1是0 → 1
0否1
2是1 → 2

常见检查点

现象检查
通过组数一直是 0检查 if report["hits"] > 0: 是否缩进在 for 里面。
通过组数太大检查 passed_count = 0 是否只在循环前写一次。
KeyError: 'hits'检查每份报告 dict 是否都有 "hits" 字段。
