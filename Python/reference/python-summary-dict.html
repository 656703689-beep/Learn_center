Reference / summary dict

总体报告

summary 是从多份 report 汇总出来的新 dict。

核心结构

summary = {
    "total_groups": len(reports),
    "passed_groups": passed_count
}
字段来源含义
"total_groups"len(reports)一共有几组报告。
"passed_groups"passed_count通过了几组。

依据：Python 官方 len() 文档和 Python 官方教程：字典。

封装成函数

def build_summary(reports):
    passed_count = 0

    for report in reports:
        if report["hits"] > 0:
            passed_count = passed_count + 1

    return {
        "total_groups": len(reports),
        "passed_groups": passed_count
    }
读法 build_summary(reports) 接收多份报告，返回一份总体报告。

常见检查点

现象检查
总组数不对确认 len() 传入的是整个 reports 列表。
通过组数不对确认 passed_count = 0 在循环前，只写一次。
函数输出 None检查 build_summary() 最后是否 return {...}。

下一步：转成 JSON

总体报告 summary 可以用 json.dumps(summary, ensure_ascii=False) 转成 JSON 字符串。详见 json.dumps 速查。
