Reference / count

数一数出现几次

count() 用来统计列表中某个值出现的次数。它返回一个整数。

核心结构

results = ["太小了", "猜中了", "太大了", "太小了"]

small_count = results.count("太小了")
print(small_count)
写法含义
results要统计的列表。
"太小了"要查找和计数的目标值。
results.count("太小了")返回 "太小了" 在 results 中出现的次数。
small_count接住这个次数的变量，本例是整数 2。

依据：Python 官方列表方法。

常见结果

results.count("太小了")  # 2
results.count("猜中了")  # 1
results.count("错误")    # 0

没找到不是报错，而是返回 0。

常见检查点

现象检查
次数总是 0检查字符串是否完全一致，例如 "太小了" 和 "太小" 不一样。
报名称不存在确认先创建了 results，再写 results.count(...)。
把 count 写在循环里看不懂本课先放在循环后统计完整结果，等数据都收集完再数。
