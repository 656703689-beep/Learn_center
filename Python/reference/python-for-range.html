Reference / for and range

数字取完，循环就停

for 负责逐个取值，range() 负责给出一串整数。先看任务的重复方式，再决定是否需要它们。

range(1, 4)
  1. take 1
  2. take 2
  3. take 3
  4. stop 4 不包含

包含 start，不包含 stop。

Core shape

最小结构

for 当前值 in 一组值:
    对当前值做一轮工作

循环结束后的工作

对应三轮训练日志：

for epoch in range(1, 4):
    print(f"第 {epoch} 轮")

print("全部完成")
部位 本例 作用
循环变量 epoch 保存这一轮取到的值
可迭代对象 range(1, 4) 依次提供 1、2、3
循环体 缩进的 print() 每取到一个值就执行一次
循环之后 顶格的 print() 所有值取完后执行一次
Range forms

三种常见写法

写法 结果 记法
range(3) 0, 1, 2 省略 start 时从 0 开始
range(1, 4) 1, 2, 3 到 4 之前停止
range(2, 7, 2) 2, 4, 6 第三个参数是 step
显示第 1 到第 N 轮 写作 range(1, n + 1)。因为 stop 不包含，所以用目标数字后面的整数作为停止边界。

range() 的参数必须是整数。当前阶段把它理解成“按需提供整数的一把尺子”即可，不需要先把它转换成列表。

Decision

while 还是 for？

先问 优先考虑 典型例子
重复次数未知，停止取决于条件？ while 一直猜，直到猜对
要依次处理一组值，或次数已知？ for 明确执行 5 轮

打开 while 循环速查，可以并排比较两种结构。

Trace

手动追踪四问

  1. range() 实际会给出哪些整数？
  2. 这一轮循环变量拿到哪个值？
  3. 缩进块改变了哪些状态？
  4. 数字取完后，哪一行最先执行？
score = 60

for epoch in range(1, 4):
    score = score + 5
    print(epoch, score)

print(score)

三轮中的 epoch 依次为 1、2、3；score 依次变为 65、70、75。

Debug

四个高频问题

症状 常见原因 检查位置
SyntaxError for 行末漏写冒号 确认最后有 :
少执行一轮 忘记 stop 不包含 检查是否需要 n + 1
某行只执行一次 它没有缩进，位于循环外 逐行标记“每轮”或“结束后”
TypeError 把小数或文本直接交给 range() 确保边界是 int
