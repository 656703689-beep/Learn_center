Reference / while loop

条件为真，就再来一轮

需要时看一眼，然后回到代码。一个可靠的 while 循环通常能回答三个问题：从什么状态开始、什么条件下继续、每轮如何接近停止。

start 设置初始状态
check 计算条件真假
update 执行并更新状态
stop 条件为假时退出
Core shape

最小结构

状态 = 初始值

while 条件:
    做一轮工作
    更新状态

循环结束后的工作

对应猜数字程序：

secret = 7
guess = 0

while guess != secret:
    guess = int(input("请猜："))

print("猜对了")
部位 本例 作用
初始状态 guess = 0 让第一次检查时变量已经存在
继续条件 guess != secret 没猜中时得到 True
状态更新 guess = int(input(...)) 让下一次检查得到新的结果
循环之后 print("猜对了") 只在条件变为 False 后执行
先检查，后执行 while 会在进入每一轮前检查条件。因此，如果条件第一次就是 False，循环体可以一次也不执行。
Trace

手动追踪四问

  1. 检查条件时，各变量当前是多少？
  2. 条件结果是 True 还是 False？
  3. 如果进入循环，这一轮改变了哪个变量？
  4. 这个改变是否让程序更接近停止？

计数器的常用写法：

attempts = 0

while guess != secret:
    guess = int(input("请猜："))
    attempts = attempts + 1

attempts = attempts + 1 是“读旧值 → 加一 → 写回新值”，不是数学等式。

Indentation

缩进决定执行时机

缩进 4 个空格

属于循环体，每进入一轮就可能执行一次。

退回最左侧

不再属于循环，只在循环结束后继续执行。

while guess != secret:
    guess = int(input("请猜："))  # 循环内

print("结束")                     # 循环外
Debug

四个高频问题

症状 常见原因 检查位置
NameError 条件第一次检查前，变量还不存在 确认循环前已有初始赋值
SyntaxError while 行末漏写冒号 确认条件后有 :
程序一直运行 循环内没有更新条件依赖的状态 确认 guess 会获得新值
输出次数不对 某行缩进在循环内外放错位置 逐行标记“每轮”或“结束后”
停止意外的无限循环 回到正在运行程序的终端，按 Ctrl + C。然后检查循环条件依赖了哪些变量，以及这些变量是否在循环中更新。
