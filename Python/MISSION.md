# Mission: Python for AI

## Why
通过 Python 打好 AI 学习的编程地基，最终能够读懂、修改并独立编写 AI 相关程序，而不是只能复制现成代码。

## Success looks like
- 能在 Windows 终端独立运行、修改和排查 Python 脚本
- 能用变量、数据类型、判断、循环和函数完成小型程序
- 能理解常见 AI 示例中的数据流，并逐步做出一个简单 AI 应用

## Constraints
- 从第一次正式 Python 学习开始，按小步实操推进
- 教学语言使用中文，Python 术语和代码保留英文
- 当前环境为 Python 3.13.14；使用 `python` 命令运行

## Out of scope
- 基础阶段暂不展开机器学习框架、模型训练和高等数学
- 不追求一次记住全部语法，优先建立“输入 → 处理 → 输出”的程序思维
