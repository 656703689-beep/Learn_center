02 · 新知识 · 4 分钟

append() 把一个值加到列表末尾

先建一个空列表：

results = []

再往里面放一个值：

results.append("太小了")
print(results)

输出是：

['太小了']

append() 的意思是：把括号里的这个值，添加到列表末尾。列表会被改变。

一句话抓住今天 print(result) 是立刻显示；results.append(result) 是先存起来，后面还能继续使用。

依据：Python 官方列表方法说明 append 会在列表末尾添加一项。

03 · 跟踪 · 3 分钟

每一轮后，results 变成什么？

results = []

results.append("太小了")
results.append("猜中了")
results.append("太大了")

print(results)
核对最后的列表 
['太小了', '猜中了', '太大了']

每次 append() 加到末尾，所以顺序和添加顺序一致。

04 · 实作 · 7 分钟

把 compare_guess 的结果收集成列表

在 Python 文件夹中新建 collect_results.py。先沿用前两天的函数，再新增一个空列表 results。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


guesses = [10, 30, 40, 25]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

print(results)
