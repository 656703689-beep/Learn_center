02 · 新增一步 · 3 分钟

打印之前，先 append 保存

如果后面还要统计、筛选、拼接这些回复，不能只靠 print()。先准备一个空列表，每轮把当前文字追加进去。

response = {
    "choices": [
        {"message": {"content": "第一步检查输入"}},
        {"message": {"content": "第二步检查条件"}}
    ]
}

contents = []

for choice in response["choices"]:
    message = choice["message"]
    content = message["content"]
    contents.append(content)

print(contents)
时刻contents 里有什么
循环前[]
第 1 轮后["第一步检查输入"]
第 2 轮后["第一步检查输入", "第二步检查条件"]
print() 是显示；append() 是保存。 保存成列表以后，下一步程序还能继续使用这些文字。

依据：Python 官方：list.append()；循环规则见 Python 官方：for 语句。

03 · 即时检查 · 1 分钟

确认 append 放在哪里

要收集每一条 content，append 应该写在哪里？

纸面学习：核对说明

答案：循环里面。每轮拿到当前 content，就在这一轮执行 contents.append(content)。
