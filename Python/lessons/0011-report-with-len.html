02 · 新知识 · 3 分钟

len() 返回列表里有几个元素

results = ["太小了", "猜中了", "太大了"]

total_count = len(results)
print(total_count)

输出是 3。因为 results 这个列表里有三个元素。

一句话抓住今天 count() 数某个值出现几次；len() 数整个列表一共有几个元素。

依据：Python 官方 len() 文档说明它返回对象的长度。

03 · 预测 · 3 分钟

区分 len 和 count

先别运行，写出两行输出：

results = ["太小了", "猜中了", "太大了", "太小了"]

print(len(results))
print(results.count("太小了"))
核对输出 
4
2

len(results) 看整个列表有几个元素；count("太小了") 只数 "太小了" 出现几次。

04 · 实作 · 8 分钟

生成“总次数 + 猜中次数 + 总结”

在 Python 文件夹中新建 report_results.py。这次新增一个函数 build_report(results)，返回一行报告。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


def suggest_from_results(results):
    hit_count = results.count("猜中了")

    if hit_count > 0:
        return "已经猜中过，测试通过"
    else:
        return "这组测试里没有猜中"


def build_report(results):
    total_count = len(results)
    hit_count = results.count("猜中了")
    summary = suggest_from_results(results)
    return f"共测试 {total_count} 次，猜中 {hit_count} 次。{summary}"


guesses = [10, 30, 40]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

report = build_report(results)

print(results)
print(report)
