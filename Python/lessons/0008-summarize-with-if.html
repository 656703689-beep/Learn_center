先取回第七天的 count()

先别运行。写出下面代码的输出：

results = ["太小了", "猜中了", "太大了", "猜中了"]

回答后核对

输出是 2。因为 "猜中了" 在列表里出现两次。

02 · 新连接 · 4 分钟

把次数交给 if

先把次数保存到变量：

hit_count = results.count("猜中了")

再判断这个次数是否大于 0：

if hit_count > 0:
    print("这组测试里猜中过")
else:
    print("这组测试里没有猜中")

读法是：如果猜中的次数大于 0，就说明至少猜中过一次；否则就是一次都没有猜中。

一句话抓住今天 count() 给出数字，if 根据这个数字选择要输出哪句话。

依据：Python 官方 if 语句与列表 count() 方法。

04 · 实作 · 8 分钟

从猜测列表到一句总结

在 Python 文件夹中新建 summarize_results.py。这次仍然先收集、再统计，最后用 if 输出总结。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


guesses = [10, 30, 40, 25]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

hit_count = results.count("猜中了")

print(results)
print("猜中了次数：", hit_count)

if hit_count > 0:
    print("这组测试里猜中过")
else:
    print("这组测试里没有猜中")
