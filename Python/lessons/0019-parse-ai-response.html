01 · 回忆 · 2 分钟

先确认 loads 的方向

先别运行。写出最后两行输出：

import json

json_text = '{"name": "第一组", "hits": 1}'

report = json.loads(json_text)

print(report["name"])
print(report["hits"])
回答后核对 
第一组
1

json.loads() 的方向是：JSON 字符串 → Python 数据。

02 · 新连接 · 4 分钟

把 AI 回复先当成 JSON 字符串

以后连接真实 AI API 时，外部系统常给 Python 一段文本。文本不能直接按 key 取值，要先解析。

import json

response_text = '{"reply": "已经收到报告", "score": 2}'

response = json.loads(response_text)

print(response["reply"])
print(response["score"])

输出：

已经收到报告
2
今天最重要的区分 response_text 是外部返回的 JSON 字符串；response 是解析后的 Python dict。

依据：Python 官方 json 文档说明 json.loads() 会把 JSON 文档字符串反序列化为 Python 对象。

03 · 预测 · 3 分钟

先预测字段输出

先别运行。写出三行输出：

import json

response_text = '{"reply": "整体偏大，可以试小一点", "small": 1, "big": 2}'

response = json.loads(response_text)

print(response["reply"])
print(response["small"])
print(response["big"])

整体偏大，可以试小一点
1
2

解析以后，response 是 Python dict，所以 response["big"] 取出数字 2。

04 · 实作 · 8 分钟

写一个模拟 AI 回复读取脚本

在 Python 文件夹中新建 ai_response.py：

import json


response_text = '{"reply": "第一组通过，第二组需要继续测试", "passed_groups": 1, "total_groups": 2}'

response = json.loads(response_text)

print("AI回复：", response["reply"])
print("通过组数：", response["passed_groups"])
print("总组数：", response["total_groups"])
