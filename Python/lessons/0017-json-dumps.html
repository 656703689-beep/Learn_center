02 · 新知识 · 4 分钟

json.dumps() 把 Python 数据转成字符串

import json

summary = {
    "total_groups": 3,
    "passed_groups": 2
}

json_text = json.dumps(summary, ensure_ascii=False)

print(json_text)

输出是一行 JSON 字符串：

{"total_groups": 3, "passed_groups": 2}
一句话抓住今天 dict 是 Python 数据；json.dumps() 生成的是可以发给外部系统的 JSON 字符串。

依据：Python 官方 json 文档说明 json.dumps(obj) 会把 Python 对象序列化为 JSON 格式的 str；ensure_ascii=False 会让中文按原样输出。

03 · 预测 · 3 分钟

中文要保留，用 ensure_ascii=False

先别运行，写出最后输出：

import json

report = {
    "name": "第一组",
    "summary": "已经猜中过，测试通过"
}

json_text = json.dumps(report, ensure_ascii=False)

print(json_text)
核对输出 
{"name": "第一组", "summary": "已经猜中过，测试通过"}

ensure_ascii=False 让中文直接显示，不变成 \u7b2c... 这种转义形式。
