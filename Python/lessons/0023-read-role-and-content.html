    ]
}

for choice in response["choices"]:

回答后核对 
先打印输入
再检查条件

choices 里有两份字典，所以循环执行两轮。

02 · 新增一步 · 3 分钟

同一份 message，可以读两个 value

现在让每个 message 同时带有 role 和 content。取法没有变：还是用 key 取 value。

response = {
    "choices": [
        {"message": {"role": "assistant", "content": "先打印输入"}},
        {"message": {"role": "assistant", "content": "再检查条件"}}
    ]
}

for choice in response["choices"]:
    message = choice["message"]
    print(message["role"])
    print(message["content"])
表达式第一轮得到什么
choice{"message": {"role": "assistant", "content": "先打印输入"}}
message{"role": "assistant", "content": "先打印输入"}
message["role"]"assistant"
message["content"]"先打印输入"
循环负责换到下一条；key 负责读取当前条里的字段。 新字段不需要新循环。只要字段在同一个 message 字典里，就在同一轮里继续用 key 读取。

依据：Python 官方：for 语句；按 key 读取 value 见官方字典教程。
