02 · 新连接 · 4 分钟

elif 表示“否则如果”

当程序有三种以上可能结果时，可以用 if / elif / else 串起来：

if small_count > big_count:
    print("整体偏小，可以试大一点")
elif big_count > small_count:
    print("整体偏大，可以试小一点")
else:
    print("偏小和偏大一样多")

Python 会从上往下检查。第一个为真的分支会执行；后面的分支就不再检查。

一句话抓住今天 if 先问第一种情况；elif 问第二种情况；else 处理前面都不满足的情况。

依据：Python 官方 if 语句中的 if / elif / else 规则。

04 · 实作 · 8 分钟

从猜测列表到建议

在 Python 文件夹中新建 suggest_results.py。这次先收集结果，再统计三类次数，最后给出建议。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


guesses = [10, 20, 25, 40]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

small_count = results.count("太小了")
big_count = results.count("太大了")
hit_count = results.count("猜中了")

print(results)
print("太小了次数：", small_count)
print("太大了次数：", big_count)
print("猜中了次数：", hit_count)

if hit_count > 0:
    print("已经猜中过，测试通过")
elif small_count > big_count:
    print("整体偏小，可以试大一点")
elif big_count > small_count:
    print("整体偏大，可以试小一点")
else:
    print("还没猜中，但偏小和偏大一样多")
