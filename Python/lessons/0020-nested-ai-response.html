Session 20 / nested dict

读取嵌套 AI 回复

上一课你读取了 response["reply"]。真实 AI 返回经常多包一层：回复文字放在 message 里面。今天学会一层一层往里取：response["message"]["content"]。

15–20 分钟 新结构：嵌套 dict AI API 常见形状
JSON 文本response_text
解析response
外层 keyresponse["message"]
内层 key["content"]
01 · 回忆 · 2 分钟

先复习上一课

先别运行。写出两行输出：

import json

response_text = '{"reply": "已经收到报告", "score": 2}'

response = json.loads(response_text)

print(response["reply"])
print(response["score"])
回答后核对 
已经收到报告
2

这是普通 dict：一个 key 直接对应一个 value。

02 · 新知识 · 4 分钟

有些 value 本身也是 dict

看这段 JSON："message" 这个 key 对应的 value 不是一句话，而是另一个对象。

import json

response_text = '{"message": {"content": "已经猜中过，测试通过"}}'

response = json.loads(response_text)

message = response["message"]

print(message["content"])

输出：

已经猜中过，测试通过
拆开看 response["message"] 先取出内层 dict；message["content"] 再从内层 dict 取出文字。

依据：Python 官方字典教程说明字典可用 key 取 value；Python 官方 json 文档说明 JSON 文本可解析成 Python 对象。

03 · 合并写法 · 3 分钟

两步可以合成一行

这两种写法结果一样：

拆开写

message = response["message"]
print(message["content"])

合起来写

print(response["message"]["content"])

刚开始建议先拆开写。看清楚以后，再合成一行。

05 · 实作 · 8 分钟

写一个嵌套 AI 回复读取脚本

在 Python 文件夹中新建 nested_response.py：

import json


response_text = '{"message": {"role": "assistant", "content": "三组都通过，可以进入下一步"}, "usage": {"total_tokens": 128}}'

response = json.loads(response_text)

message = response["message"]
usage = response["usage"]

print("角色：", message["role"])
print("内容：", message["content"])
print("token数量：", usage["total_tokens"])
