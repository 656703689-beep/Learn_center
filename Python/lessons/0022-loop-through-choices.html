01 · 回忆 · 1 分钟

先读第一条

先别运行，写出这一行 print() 的输出。

response = {
    "choices": [
        {"message": {"content": "先检查输入"}},
        {"message": {"content": "再核对结果"}}
    ]
}

print(response["choices"][0]["message"]["content"])
回答后核对 
先检查输入

[0] 取第一份字典，后面的 key 继续取出文字；输出不带 content:。

这段 response 直接写成 Python 字典，用来集中练习取值。

02 · 连接旧知识 · 3 分钟

每一轮，拿到一份 choice

保留上面的 response，把最后的 print() 换成：

choices = response["choices"]

for choice in choices:
    message = choice["message"]
    print(message["content"])

for 按列表顺序，逐个把元素交给 choice。每拿到一份字典，就执行一次缩进里的两行。

轮次当前 choice这一轮输出
第 1 轮{"message": {"content": "先检查输入"}}先检查输入
第 2 轮{"message": {"content": "再核对结果"}}再核对结果
choices 是整个 list；choice 是当前的一份 dict。 choice 是自己起的变量名。每轮已经取到一个元素，所以接着用 ["message"] 读取它。
看懂后，再看合并写法 
for choice in response["choices"]:
    print(choice["message"]["content"])

两种写法结果一样。先用中间变量，看清每一步的数据。

依据：Python 官方：for 语句；按 key 取 value 见官方字典教程。

03 · 即时检查 · 1 分钟

确认每轮拿到什么

在本课的循环中，每一轮的 choice 是什么？

纸面学习：核对说明

答案：一份字典。for 取出的是一个列表元素；本例的每个元素都是包含 message 的字典。

04 · 亲手完成 · 4 分钟

从 JSON 文本读出两条回复

在 Python 文件夹新建 all_choices.py。先写下面三行，再自己补上读取 choices 的循环。

import json

response_text = '{"choices": [{"message": {"content": "可以先检查输入"}}, {"message": {"content": "也可以核对输出"}}]}'
response = json.loads(response_text)

# 在下面补全：逐份读取 message，再打印 content

这是同一次模拟响应里的两份回复数据。json.loads() 先把文本解析成 Python 数据，之后就能使用本课的循环。

解析规则：Python 官方：json.loads()。本课只处理上面给定的数据结构。
