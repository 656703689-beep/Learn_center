Session 02 / repeat with a condition

让程序再来一次

第一天，程序判断一次就结束。今天你给它加上一条停止规则：只要还没猜对，就继续接收输入；一旦猜对，自动走出循环。

先不看旧代码，叫醒第一天的知识

请先口头回答，再展开核对。不是考试；费力回忆，正是让记忆变牢的步骤。

Q1：input() 接收数字 7 后，返回的类型是什么？

是 str。要和整数 secret 比较，需要先用 int() 转换。

Q2：= 和 == 分别做什么？

= 给变量赋值；== 判断两边是否相等，并得到 True 或 False。

Q3：哪件事决定一行代码属于 if？

缩进。冒号后的分支代码通常缩进 4 个空格；退回原来的缩进层级，就表示已经走出该代码块。

Understand

while：先检查，再决定是否重复

while 的含义是：只要条件仍为 True，就执行缩进的代码块，然后回来重新检查条件。

guess = 0

while guess != 7:
    guess = int(input("请猜："))

print("循环结束")

1. 初始状态

guess = 0 让变量在第一次检查前已经存在，而且暂时不等于秘密数字。

2. 循环条件

guess != 7 问的是“还没猜对吗？”；答案为真，才进入缩进块。

3. 状态更新

循环里必须给 guess 新值，条件才有机会从 True 变为 False。

最重要的安全问题 如果循环里的数据永远不会让条件变成 False，程序会一直循环。需要停止正在运行的程序时，在终端按 Ctrl + C。

运行前预测

下面的程序会输出几次 再猜？先选：零次输出 / 一次输出 / 无限输出。

guess = 3

while guess != 7:
    print("再猜")
    guess = 7

print("结束")
展开预测答案

一次输出。第一次检查时 3 != 7 为真，因此输出一次；随后 guess 变成 7。第二次检查为假，循环结束。

Checkpoint 1 · Build

把单次判断升级为反复猜

在 Python 文件夹中新建 guess_until_right.py，亲手输入下面的代码。先关注缩进层级，不追求速度。

secret = 7
guess = 0
attempts = 0

while guess != secret:
    guess = int(input("猜一个 1～10 的整数："))
    attempts = attempts + 1

    if guess < secret:
        print("小了")
    elif guess > secret:
        print("大了")

print(f"猜对了！你一共猜了 {attempts} 次。")

保存后，在 PowerShell 里运行：

cd "C:\Users\ZhongHui\Documents\ChatGPT\学习\Python"
python guess_until_right.py
固定测试路线 依次输入 3、9、7。你应依次看到“小了”“大了”，最后看到“猜对了”以及 3 次。
为什么猜对时不用在 if 里再写 else？

猜中时，guess < secret 和 guess > secret 都为假，所以不会输出大小提示。循环体执行完后重新检查 guess != secret，此时为假；程序退出循环，再执行最外层的“猜对了”。

attempts = attempts + 1 到底发生了什么？

先读取右边当前的 attempts，加 1，再把新结果赋回同一个变量。每进入一次循环、接收一次猜测，计数就增加一次。

Checkpoint 2 · Trace

用一张表看见程序的状态

对于输入 3 → 9 → 7，每一轮都会改变 guess 和 attempts。这两个会随运行变化的值，就是程序的状态。

检查时刻 guess guess != secret 本轮动作 attempts
第一次检查 0 True 输入 3，输出“小了” 1
第二次检查 3 True 输入 9，输出“大了” 2
第三次检查 9 True 输入 7，不输出大小 3
第四次检查 7 False 退出循环，输出结果 3
连接到 AI 目标 很多交互式程序都会重复“读取输入 → 更新状态 → 检查是否停止”。以后你读 AI 应用或 Agent 示例时，也会经常看到这种控制流；今天先掌握它最小、可验证的版本。
Checkpoint 3 · Debug

用症状定位缩进问题

完成固定测试后，把最后一行临时缩进 4 个空格，让它进入 while，再用 3 → 9 → 7 运行一次。观察“猜对了”出现的位置，然后恢复原来的缩进。

你应该观察到什么？

“猜对了”会在每次错误猜测后也出现，因为它已经属于循环体。恢复为顶格后，它只会在循环结束时执行一次。这个实验说明：缩进不仅影响格式，还改变程序的执行时机。

Retrieval · Finish

合上代码，用自己的话回答

Q1：while 在每一轮开始前做什么？

重新计算条件。条件为 True 就进入循环体；为 False 就跳到循环之后。

Q2：为什么 guess 要在循环里更新？

循环条件依赖 guess。更新它，条件才可能从真变为假，让程序正常停止。

Q3：输入 3、9、7 时，while 的循环体执行几次？

执行 3 次。猜中后的第四次条件检查仍会发生，但条件为假，所以不会第四次进入循环体。

Q4：哪一行代码真正决定循环结束？

while guess != secret: 中的条件决定是否继续；循环内更新 guess，让这个条件最终变为假。
