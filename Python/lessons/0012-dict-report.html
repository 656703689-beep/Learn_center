01 · 回忆 · 2 分钟

先取回 len 和 count

先别运行。写出两行输出：

results = ["太小了", "猜中了", "太大了", "太小了"]

print(len(results))
print(results.count("猜中了"))
回答后核对 
4
1

len(results) 数全部元素；count("猜中了") 只数猜中出现几次。

02 · 新知识 · 4 分钟

dict 是“带名字的数据盒子”

report = {
    "total": 3,
    "hits": 1,
    "summary": "已经猜中过，测试通过"
}

print(report["hits"])

输出是 1。因为 "hits" 这个名字对应的值是 1。

一句话抓住今天 list 靠顺序保存多个值；dict 靠名字保存多个值。
写法含义
"total": 3"total" 是 key，3 是 value。
report["total"]从 report 里取出名字叫 "total" 的值。
report["summary"]取出总结文字。

依据：Python 官方教程：字典说明字典是键值对集合，主要操作是通过 key 存储和提取 value。

04 · 实作 · 8 分钟

让 build_report 返回 dict

在 Python 文件夹中新建 dict_report.py。这次 build_report(results) 不再返回一句字符串，而是返回一个 dict。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


def suggest_from_results(results):
    hit_count = results.count("猜中了")

    if hit_count > 0:
        return "已经猜中过，测试通过"
    else:
        return "这组测试里没有猜中"


def build_report(results):
    total_count = len(results)
    hit_count = results.count("猜中了")
    summary = suggest_from_results(results)

    return {
        "total": total_count,
        "hits": hit_count,
        "summary": summary
    }


guesses = [10, 30, 40]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

report = build_report(results)

print(results)
print(report)
print("总次数：", report["total"])
print("猜中次数：", report["hits"])
print("总结：", report["summary"])
