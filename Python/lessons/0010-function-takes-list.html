02 · 新连接 · 4 分钟

参数可以接收整个列表

函数的参数不只能接收一个数字，也可以接收一个列表：

def suggest_from_results(results):
    hit_count = results.count("猜中了")

    if hit_count > 0:
        return "已经猜中过，测试通过"
    else:
        return "这组测试里没有猜中"

调用时，把整个列表作为实参传进去：

summary = suggest_from_results(["太小了", "猜中了", "太大了"])
print(summary)

这里的 results 参数接到的是整个列表，不是列表里的某一个字符串。

一句话抓住今天 以前函数处理一个 guess；今天函数处理一整个 results 列表。

依据：Python 官方函数定义、return 语句与列表 count() 方法。

04 · 实作 · 8 分钟

把建议逻辑封装成函数

在 Python 文件夹中新建 summary_function.py。这次主程序只负责收集结果；建议由 suggest_from_results(results) 返回。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


def suggest_from_results(results):
    small_count = results.count("太小了")
    big_count = results.count("太大了")
    hit_count = results.count("猜中了")

    if hit_count > 0:
        return "已经猜中过，测试通过"
    elif small_count > big_count:
        return "整体偏小，可以试大一点"
    elif big_count > small_count:
        return "整体偏大，可以试小一点"
    else:
        return "还没猜中，但偏小和偏大一样多"


guesses = [35, 40, 20]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

summary = suggest_from_results(results)

print(results)
print(summary)
