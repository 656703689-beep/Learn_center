Session 18 / json.loads

把 JSON 转回 Python 数据

上一课你用 json.dumps() 把 Python 数据转成 JSON 字符串。今天反过来：用 json.loads() 把 JSON 字符串转回 Python 的 dict 或 list。

15–20 分钟 新工具：json.loads 旧工具：dict key
JSON 字符串json_text
导入模块import json
转换json.loads(...)
Python 数据data["hits"]
01 · 回忆 · 2 分钟

先取回 dumps 的方向

先别运行。写出最后输出：

import json

summary = {
    "total_groups": 3,
    "passed_groups": 2
}

json_text = json.dumps(summary, ensure_ascii=False)

print(json_text)
回答后核对 
{"total_groups": 3, "passed_groups": 2}

dumps 的方向是：Python 数据 → JSON 字符串。

02 · 新知识 · 4 分钟

json.loads() 把 JSON 字符串转回 Python 数据

import json

json_text = '{"name": "第一组", "hits": 1}'

report = json.loads(json_text)

print(report["name"])
print(report["hits"])

输出：

第一组
1
一句话抓住今天 dumps 是 Python 数据变 JSON 文本；loads 是 JSON 文本变 Python 数据。

依据：Python 官方 json 文档说明 json.loads() 会把包含 JSON 文档的字符串反序列化为 Python 对象。

03 · 预测 · 3 分钟

转回来以后，可以按 key 取值

先别运行，写出两行输出：

import json

json_text = '{"total_groups": 3, "passed_groups": 2}'

summary = json.loads(json_text)

print(summary["total_groups"])
print(summary["passed_groups"])
核对输出 
3
2

summary 已经从 JSON 字符串变回 Python dict，所以能用 key 取值。

04 · 实作 · 8 分钟

读取一份 JSON 报告

在 Python 文件夹中新建 json_read.py。这次从 JSON 字符串开始，转回 Python 数据后再取字段。

import json


json_text = '{"name": "第一组", "hits": 1, "summary": "已经猜中过，测试通过"}'

report = json.loads(json_text)

print(report)
print("组名：", report["name"])
print("猜中次数：", report["hits"])
print("总结：", report["summary"])

读取 reports 列表

把文件改成：

import json


json_text = '[{"name": "第一组", "hits": 1}, {"name": "第二组", "hits": 0}]'

reports = json.loads(json_text)

for report in reports:
    print(report["name"])
    print(report["hits"])
