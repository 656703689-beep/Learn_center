02 · 新知识 · 3 分钟

把多个值放进方括号

guesses = [10, 30, 40]

guesses 保存一个列表（list）；方括号 [] 内用英文逗号分隔，每个值叫一个元素。这里共有三个元素，按顺序是 10、30、40。

接上已经学过的 for：

guesses = [10, 30, 40]

for guess in guesses:
    print(guess)

这行读作：“从 guesses 中依次取出一个值，赋给 guess，再执行缩进的代码。”

一整组与本轮的一个 guesses 是整个列表；guess 是这一轮取出的数字。这两个名字由我们选择，单复数只是帮助阅读的命名习惯。

依据：官方列表教程与for 按顺序遍历元素的规则。

range(1, 4) 提供的是 1、2、3；这里列表已经提供了要处理的数字，所以直接写 for guess in guesses:。

04 · 实作 · 6 分钟

用一个循环检查三个猜测

在 Python 文件夹中新建 batch_guesses.py。沿用第四天的函数，亲手补上列表和循环。今天做的是检查多组测试输入，每个数字都要得到结果。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


guesses = [10, 30, 40]
secret = 30

for guess in guesses:
    result = compare_guess(guess, secret)
    print(f"{guess}：{result}")

print("全部检查完成")

运行前先预测输出。这里的数据已写在列表中，程序会直接检查，不需要键盘输入。

运行后核对完整输出 
10：太小了
30：猜中了
40：太大了
全部检查完成

每轮接收一次返回值并打印；最后一句在循环外，只打印一次。

第二轮已经 return，为什么还能检查 40？

return 结束的是这一次函数调用。主程序接到结果后继续打印，再由 for 取出下一个元素。这个循环里没有 break，因此会检查完整个列表。

依据：return 结束当前函数调用。
