01 · 回忆 · 2 分钟

先复习嵌套 dict

先别运行。写出输出：

import json

response_text = '{"message": {"content": "第二组还没有通过"}}'

response = json.loads(response_text)

print(response["message"]["content"])
回答后核对 
第二组还没有通过

response["message"] 先取内层 dict，再用 ["content"] 取文字。

02 · 新知识 · 5 分钟

choices 是 list，所以用 [0]

看这段更像真实 AI 返回的 JSON。"choices" 对应的 value 是一个 list，列表里第一个元素才是那份回复 dict。

import json

response_text = '{"choices": [{"message": {"content": "已经猜中过，测试通过"}}]}'

response = json.loads(response_text)

choices = response["choices"]
first_choice = choices[0]
message = first_choice["message"]

print(message["content"])

输出：

已经猜中过，测试通过
两个规则合在一起 dict 用 key：response["choices"]。list 用 index：choices[0]。

依据：Python 官方列表教程说明列表用方括号索引取元素；Python 官方字典教程说明字典用 key 取 value。

03 · 合并写法 · 3 分钟

拆开看，再合起来

拆开写

choices = response["choices"]
first_choice = choices[0]
message = first_choice["message"]
print(message["content"])

合起来写

print(response["choices"][0]["message"]["content"])

含义完全一样。刚开始写长链条时，建议先拆开，方便看清每一步拿到的是什么。

05 · 实作 · 8 分钟

写一个 choices 回复读取脚本

在 Python 文件夹中新建 choices_response.py：

import json


response_text = '{"choices": [{"message": {"role": "assistant", "content": "第一组通过，第二组继续测试"}}], "usage": {"total_tokens": 156}}'

response = json.loads(response_text)

choices = response["choices"]
first_choice = choices[0]
message = first_choice["message"]
usage = response["usage"]

print("角色：", message["role"])
print("内容：", message["content"])
print("token数量：", usage["total_tokens"])
