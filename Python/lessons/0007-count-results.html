02 · 新知识 · 4 分钟

count() 返回出现次数

看这个列表：

results = ["太小了", "猜中了", "太大了", "太小了"]

如果要数 "太小了" 出现几次：

too_small_count = results.count("太小了")
print(too_small_count)

输出是：

2

count() 会在整个列表里数一遍，返回目标值出现的次数。没有出现时，结果是 0。

一句话抓住今天 append() 是把结果放进列表；count() 是从列表里数某个结果出现几次。

依据：Python 官方列表方法说明 count() 返回某个值出现的次数。

04 · 实作 · 8 分钟

先收集，再统计

在 Python 文件夹中新建 count_results.py。这次先得到 results，再统计每类结果。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


guesses = [10, 30, 40, 25]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

print(results)
print("太小了次数：", results.count("太小了"))
print("太大了次数：", results.count("太大了"))
print("猜中了次数：", results.count("猜中了"))
