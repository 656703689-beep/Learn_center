02 · 新知识 · 4 分钟

dict 可以继续增加字段

字段就是一组 key: value。要多保存两个数字，就多写两行。

report = {
    "total": 4,
    "hits": 0,
    "small": 3,
    "big": 1,
    "summary": "整体偏小，可以试大一点"
}

print(report["small"])
print(report["big"])

输出是 3 和 1。因为 "small" 对应 3，"big" 对应 1。

一句话抓住今天 dict 里想保存更多信息，就增加更多 key: value。

依据：Python 官方教程：字典说明字典是 key-value 集合，主要操作是通过 key 存储和提取 value。

03 · 预测 · 3 分钟

report = {

04 · 实作 · 8 分钟

让报告同时保存 small、big、hits

在 Python 文件夹中新建 dict_fields.py。这次 build_report(results) 返回更完整的 dict。

def compare_guess(guess, secret):
    if guess < secret:
        return "太小了"
    elif guess > secret:
        return "太大了"
    else:
        return "猜中了"


def suggest_from_counts(small_count, big_count, hit_count):
    if hit_count > 0:
        return "已经猜中过，测试通过"
    elif small_count > big_count:
        return "整体偏小，可以试大一点"
    elif big_count > small_count:
        return "整体偏大，可以试小一点"
    else:
        return "偏小和偏大一样多"


def build_report(results):
    total_count = len(results)
    small_count = results.count("太小了")
    big_count = results.count("太大了")
    hit_count = results.count("猜中了")
    summary = suggest_from_counts(small_count, big_count, hit_count)

    return {
        "total": total_count,
        "small": small_count,
        "big": big_count,
        "hits": hit_count,
        "summary": summary
    }


guesses = [10, 20, 40, 30]
secret = 30
results = []

for guess in guesses:
    result = compare_guess(guess, secret)
    results.append(result)

report = build_report(results)

print(results)
print(report)
print("偏小次数：", report["small"])
print("偏大次数：", report["big"])
print("猜中次数：", report["hits"])
print("总结：", report["summary"])
