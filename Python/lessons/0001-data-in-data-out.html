Checkpoint 2

练习一：温度换算

打开 study_log.py，在文件末尾亲手输入下面四行。先不要复制粘贴；慢一点敲，留意引号、括号和变量名。

celsius = float(input("请输入摄氏温度："))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius}°C = {fahrenheit:.1f}°F")
print("温度换算完成")

保存后重新运行 python study_log.py。依次测试：

  • 输入 0，应得到 32.0°F
  • 输入 100，应得到 212.0°F
为什么这里用 float，不用 int？

温度可能是 36.5。float("36.5") 可以转换，int("36.5") 会触发 ValueError。选择类型要看数据可能长什么样。

Checkpoint 3

练习二：BMI 计算

公式是：BMI = 体重（kg）÷ 身高（m）的平方。先自己把三个空补出来，再展开答案核对。

weight = float(input("体重（kg）："))
height = float(input("身高（m）："))
bmi = ________
print(f"你的 BMI 是 ________")
测试数据 体重输入 60、身高输入 1.70，结果约为 20.76。Python 中平方写作 ** 2。
核对 BMI 代码 
weight = float(input("体重（kg）："))
height = float(input("身高（m）："))
bmi = weight / (height ** 2)
print(f"你的 BMI 是 {bmi:.2f}")

:.2f 表示把浮点数显示为小数点后两位。它改变显示方式，不会把变量本身变成文本。

Checkpoint 4

练习三：猜数字，第一次使用缩进

把秘密数字固定为 7。程序根据猜测进入三个分支之一。冒号后的四个空格决定哪条输出属于哪个分支。

secret = 7
guess = int(input("猜一个 1～10 的整数："))

if guess == secret:
    print("猜对了")
elif guess < secret:
    print("小了")
else:
    print("大了")

分别输入 7、3、9，确认三个分支都实际运行过。

错误实验：故意弄坏一次，再修好 暂时删掉 print("猜对了") 前面的 4 个空格并运行。记录报错最后一行；然后把 4 个空格加回来，再次运行。你应该看到 IndentationError，也应该能独立消除它。
为什么缩进不只是“让代码好看”？

Python 用缩进划定代码块。它决定某行是否属于 if、elif 或 else。缺少或不一致的缩进会让解析器无法确定程序结构，因此属于语法问题。

Q1：键入 45 后，input() 返回 int 还是 str？

返回 str，值可写成 "45"。需要计算时再用 int() 或 float() 转换。

Q2：print() 与 input() 各负责什么？

input() 把用户输入带进程序；print() 把程序中的值显示到终端。一个负责进入，一个负责出来。

Q3：为什么变量名拼错会报 NameError？

Python 按名字寻找已经绑定的值。minutes 与 minute 是两个不同名字；如果后者从未赋值，Python 就找不到它。

Q4：为什么 if 后面的输出要缩进？

缩进表示输出属于该判断分支。Python 通过缩进理解代码块边界，而不使用大括号。

Q5：AI 目标与今天的小程序有什么关系？

AI 应用也要接收输入、把输入整理为正确类型或结构、交给程序处理，再输出结果。今天建立的是这条数据流的最小模型。
