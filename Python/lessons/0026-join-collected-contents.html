02 · 新增一步 · 3 分钟

用分隔符把列表合成文本

join() 的形状有点反直觉：分隔符写在前面，列表写在括号里。

contents = ["先检查输入", "再检查条件", "最后整理回答"]

final_text = "\n".join(contents)

print(final_text)

输出会变成三行普通文本：

先检查输入
再检查条件
最后整理回答
代码分隔符结果形状
"\n".join(contents)换行一行一个回复
"，".join(contents)中文逗号合成一句话
本课只记一句： 要把多条字符串合成一段文本，用 分隔符.join(列表)。

依据：Python 官方：str.join() 会把 iterable 里的字符串拼接成一个新字符串，分隔符由调用它的字符串提供。

04 · 亲手完成 · 3 分钟

新建 final_text.py

在 Python 文件夹中新建 final_text.py。先写下面代码，再自己补全合并文本的一行。

import json

response_text = '{"choices": [{"message": {"role": "assistant", "content": "先检查输入"}}, {"message": {"role": "assistant", "content": "再检查条件"}}, {"message": {"role": "assistant", "content": "最后整理回答"}}]}'
response = json.loads(response_text)

contents = []

for choice in response["choices"]:
    message = choice["message"]
    content = message["content"]
    contents.append(content)

# 在下面补全：把 contents 合并成一段文本，一条回复一行

print(final_text)

目标输出：

先检查输入
再检查条件
最后整理回答
