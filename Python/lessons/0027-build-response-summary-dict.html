02 · 新增一步 · 3 分钟

把多个结果放进一个 dict

当一个程序产生多个结果时，用 dict 给每个结果起名字。后续代码就能通过 key 读取需要的字段。

contents = ["先检查输入", "再检查条件"]
reply_count = len(contents)
final_text = "\n".join(contents)

summary = {
    "contents": contents,
    "reply_count": reply_count,
    "final_text": final_text
}

print(summary["reply_count"])
print(summary["final_text"])
keyvalue 来自哪里用途
"contents"contents 列表保留每条原始回复
"reply_count"len(contents) 的结果知道一共有几条
"final_text""\n".join(contents) 的结果拿到最终可读文本
本课只记一句： dict 用 key 给结果命名，后面用同一个 key 把 value 取出来。

依据：Python 官方：字典 说明字典通过 key 存储和提取 value。

新建 response_summary.py

在 Python 文件夹中新建 response_summary.py。先写下面代码，再自己补全 summary 字典。

import json

response_text = '{"choices": [{"message": {"role": "assistant", "content": "先检查输入"}}, {"message": {"role": "assistant", "content": "再检查条件"}}, {"message": {"role": "assistant", "content": "最后整理回答"}}]}'
response = json.loads(response_text)

contents = []

for choice in response["choices"]:
    message = choice["message"]
    content = message["content"]
    contents.append(content)

reply_count = len(contents)
final_text = "\n".join(contents)

# 在下面补全：把 contents、reply_count、final_text 放进 summary

print(summary["reply_count"])
print(summary["final_text"])
