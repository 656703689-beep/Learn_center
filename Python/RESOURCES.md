# Python for AI Resources

## Knowledge

- [Python 3.13 教程：使用 Python 的解释器](https://docs.python.org/zh-cn/3.13/tutorial/interpreter.html)
  Python 官方对交互模式、脚本模式和启动命令的说明。用于：运行第一个程序、区分终端命令与 Python 代码。
- [Python 3.13 教程：Python 速览](https://docs.python.org/zh-cn/3.13/tutorial/introduction.html)
  Python 官方对数字、字符串、赋值、变量和缩进的入门讲解。用于：前几课的基本语法。
- [Python 3.13：内置函数](https://docs.python.org/zh-cn/3.13/library/functions.html#input)
  `input()`、`print()`、`int()`、`float()` 和 `type()` 的权威定义。用于：确认输入输出与类型转换的行为。
- [Python 3.13 教程：错误和异常](https://docs.python.org/zh-cn/3.13/tutorial/errors.html)
  官方说明如何阅读 `SyntaxError`、`NameError`、`TypeError` 等错误。用于：把报错当作定位线索。
- [Python 3.13 语言参考：缩进](https://docs.python.org/zh-cn/3.13/reference/lexical_analysis.html#indentation)
  Python 如何用缩进生成代码块的正式规则。用于：理解缩进不是排版装饰，而是语法。

## Wisdom (Communities)

- [Python Help — discuss.python.org](https://discuss.python.org/c/users/7)
  Python 官方社区的使用求助区。用于：携带最小复现代码询问真实开发问题。
- [Python Community — Python.org](https://www.python.org/community/)
  Python 软件基金会维护的社区入口，列出论坛、Python Discord 等渠道。用于：后续寻找同阶段学习者和实践反馈。
