# TypeScript 开发五级学习路线

> 目标：从 TS 完全新手到能独立做项目。业余时间约 4–6 个月。
> 前置要求：Python 基础（会用函数、列表、字典、pip 即可），TypeScript 零基础。
> 想先快速上手？[00_20小时速通计划.md](00_20小时速通计划.md) 是本路线的 10 次 × 2 小时浓缩版——覆盖等级 1–2 全部、等级 3 核心、等级 4 最小实操、等级 5 迷你版。速通完想深入，从等级 3 接着走。
> 与 AI_agent 课程的关系：那边课件已改用 TypeScript，本路线是它的语言基础。等级 1–2 学完再跟那边的课会顺很多。
> 用法：每完成一项练习或达标一项标准，把 `[ ]` 改成 `[x]`。所有晋级标准打勾后，再进入下一等级。

## 等级 1：环境与语法起步——会写会跑（约 2–3 周）

**核心认知：TypeScript = JavaScript + 编译期类型检查。类型在编译后会被完全擦除，管不到运行时。**
这个认知没建立，你会一直疑惑"编译器明明说没问题，为什么跑起来还是炸了"。

### 需要掌握
- 环境与运行：Node 是什么、npm/npx 的关系；两种跑 TS 的方式——`tsc` 编译 vs `npx tsx` 直跑（日常用后者）
- 变量与类型：`let`/`const`（忘掉 var）；原始类型 `string`/`number`/`boolean`/`null`/`undefined`
- 类型注解 vs 类型推断：什么时候必须写、什么时候让编译器自己推
- 联合类型 `string | number`、字面量类型 `"small" | "large"`
- 数组 `string[]`、对象类型的写法、函数参数与返回值类型
- `strict` 模式的概念：为什么新项目必须开

### 常见错误
- 一报错就写 `any` 求清净——any 一多，TS 就退化回 JS，白学
- 不理解推断的两个极端：要么每行都手动注解，要么完全不写注解也不敢读复杂类型
- 以为类型能挡住运行时错误——`JSON.parse`、用户输入、网络返回的数据都不受类型保护
- Python 习惯直接平移：`==` 的隐式转换、`0`/`""`/`null` 的 truthy 陷阱、数字和字符串直接拼接
- 抄网上教程的陈年 tsconfig（target ES5、不开 strict）——配置过时，学到的也是过时的

### 练习（代码放 `01_语法起步/`）
- [ ] BMI 计算器：输入身高体重，输出分级——分级结果用字面量联合类型
- [ ] 猜数字命令行游戏：循环 + 读取用户输入，体会 `string` 转 `number` 的坑
- [ ] 内存通讯录：对象数组的增删改查，每个操作一个函数，练类型注解
- [ ] 找一段 100 行左右的网上 JS 代码，改成 strict 下 0 error 的 TS

### 晋级标准
- [ ] 不查资料写出 200 行左右的纯逻辑 TS 脚本，strict 下 0 error
- [ ] 能向别人讲清"类型擦除"：为什么 TS 的类型管不到运行时
- [ ] 能说出 `any` 为什么大多数时候是债务，而不只是"消报错的快捷键"

## 等级 2：类型系统核心——用类型建模数据（约 3–4 周）

**类型的真正价值不是"编译器不报错"，而是逼你在写代码之前把数据的形状想清楚；窄化（narrowing）是日常写 TS 用得最多的机制。**

### 需要掌握
- `interface` vs `type` 别名：区别与取舍
- 可选属性 `?`、只读 `readonly`
- 可空类型：strict 下的 `null`/`undefined`、可选链 `?.`、空值合并 `??`
- 窄化的全部手段：`typeof`、`instanceof`、`in`、真值窄化
- **判别联合（discriminated union）**——用类型建模业务状态的核心武器
- `as const`、元组 `[string, number]`
- 类型断言 `as`、`unknown` 与 `any` 的本质区别、自定义类型守卫 `x is Foo`
- `enum` 的坑：为什么很多团队禁用它、用 `as const` 对象替代

### 常见错误
- 可能为 null/undefined 的值直接 `.xxx`，strict 下满屏红就烦躁地加 `!` 或 `as`
- 用 `as` 强转代替窄化——把"我不想想清楚"伪装成"我确定"，运行时照样炸
- Python 的可变性直觉直接平移：对象赋值是共享引用，函数里改了、外面也跟着变
- 用一堆 boolean 字段模拟状态（`isPaid` + `isShipped` + `isCancelled`），组合出大量非法状态——该用判别联合
- 把 interface 当 Python class 用，什么都想包成"类"——TS 里大多数场景是纯数据 + 函数

### 练习（代码放 `02_类型建模/`）
- [ ] 订单状态机：pending → paid → shipped / cancelled，用判别联合建模 + `switch` 穷尽检查（`never`），故意写一个非法流转验证编译器会拒绝
- [ ] 手写解析器：把 `unknown`（模拟 `JSON.parse` 的结果）一步步守卫成类型安全的对象——全程禁止 `as any`
- [ ] 命令行待办事项（内存版）：任务带 `status: todo/doing/done`，所有操作函数完整类型化

### 晋级标准
- [ ] 能用判别联合 + `never` 穷尽检查建模一个状态机：新增状态时，漏处理的分支会编译报错
- [ ] 面对 `unknown` 数据，第一反应是写类型守卫，而不是 `as any`
- [ ] 能讲清 interface 与 type 的取舍、enum 为什么慎用

## 等级 3：工程化与异步——做出真实小工具（约 4–6 周）

**异步是 JS/TS 的主旋律；类型安全的第一道防线在数据进来的边界（网络、文件、用户输入）——类型只管编译期，边界处必须做运行时校验。**

### 需要掌握
- ESM 模块：`import`/`export`、默认导出的坑；多文件项目怎么组织
- package.json：dependencies vs devDependencies、semver 版本号怎么看、锁文件是什么
- Promise 是什么、`async`/`await`、`try/catch` 捕获异步错误、`Promise.all` / `allSettled` 并发
- `fetch`：检查 `res.ok`、处理超时与网络错误、解析 JSON
- 用 zod（或等级 2 的手写守卫）在边界校验一次，之后全程类型安全
- 泛型初见：先不用自己写，看懂 `Array<string>`、`Promise<User>`、`Record<string, T>`
- `Map`/`Set`；`node:fs` 读写文件、JSON 持久化
- 怎么挑 npm 包：维护状态、类型是否自带、周下载量

### 常见错误
- 忘了 `await`：拿着 Promise 当结果用，打出 `[object Promise]` 或满屏 `Promise<...>`
- async 函数里的错误没人接，一崩整个程序挂
- 不检查 `res.ok`（404/500 也会进 then）、不 try 网络错误
- 把 `JSON.parse` 或 API 返回的数据直接当类型安全的数据用——一句 `as` 骗过编译器，运行时炸
- 抄来的 tsconfig 不知道 strict 开没开；一个项目里 `require` 和 `import` 混用
- 见包就装：20 行能写完的功能装了 3 个依赖，装完还不知道哪个在干活

### 练习（代码放 `03_工程与异步/`）
- [ ] 天气 CLI：调真实公开 API（open-meteo 不用注册），命令行参数 + 错误处理 + zod 校验返回值
- [ ] 并发抓取器：给一组 URL，用 `Promise.allSettled` 并发抓取，单个失败不中断整体，最后输出成功/失败报告
- [ ] 待办事项升级：把等级 2 的内存版改为 JSON 文件持久化——读的时候校验，坏数据要有兜底
- [ ] 衔接练习：给 AI_agent 第 1 课的 LLM API 调用加上 zod 校验——两门课在这里直接打通

### 晋级标准
- [ ] `npm init` 从零建项目，到多文件 CLI 跑通，全程不复制别人的配置
- [ ] 每条异步错误路径（断网、API 404、JSON 损坏）都有处理，程序不裸崩
- [ ] 会自己评估一个包该不该装，说得出理由

## 等级 4：进阶类型与代码质量——写出可复用的代码（约 1–2 月）

**高级类型是为"复用"服务的，不是炫技；能看懂流行库的类型签名，是从"会用"到"能独立排查问题"的门槛。**

### 需要掌握
- 自己写泛型：泛型函数、泛型接口、约束 `extends`、`keyof`、泛型默认值
- 工具类型：`Partial` / `Pick` / `Omit` / `Record` / `ReturnType` / `Awaited`，并理解它们如何由映射类型实现
- `keyof`、映射类型 `in`、条件类型 `extends ? :` 基础、`infer` 初见
- 类与 `implements`（了解即可——现代 TS 项目函数优先，类不是主角）
- 用 vitest 写单元测试：`describe`/`it`/`expect`，优先测纯函数
- ESLint（typescript-eslint）+ Prettier；strict 家族开关逐个理解（含 `noUncheckedIndexedAccess`）
- 声明文件 `.d.ts` 是什么、给没有类型的包怎么补

### 常见错误
- 类型体操上瘾：三行逻辑配二十行类型，同事看不懂，自己三天后也看不懂
- 泛型乱加：能写具体类型的地方硬抽泛型，抽象抽错了方向
- 不写测试，重构全靠胆量；或者走向另一个极端，给 get 函数凑 100% 覆盖率
- lint 报错就 `eslint-disable`，而不是理解规则为什么存在
- `any` 从依赖边界渗进核心代码：边界漏了校验，里面只能一路 any 下去
- 跟着过时教程用 class + 继承搭一切，不知道函数 + 类型 often 更简单

### 练习（代码放 `04_进阶与质量/`）
- [ ] 泛型工具库：`groupBy`、`debounce`、`deepClone`、`chunk` 等，带完整泛型类型 + vitest 测试
- [ ] 回炉重构：给等级 2、3 的项目补上测试，然后做一次结构性重构，靠测试证明没改坏
- [ ] 精读一个流行库的类型（zod 或 hono 的部分 `.d.ts`），写笔记讲清 3 个你原本看不懂的签名

### 晋级标准
- [ ] 能写出带约束的泛型函数（如 `pluck<T, K extends keyof T>(objs: T[], key: K): T[K][]`）
- [ ] 拿到一个主流库，能读懂公开类型签名并按签名正确使用
- [ ] 完成过一次有测试护航的重构：结构变了，测试证明行为没变

## 等级 5：独立项目——从想法到交付（约 1–2 月）

**独立做项目 = 需求拆解 + 技术选型 + 交付质量（错误处理、测试、文档、部署）。编码只占一半，另一半是把"我做完了"变成"别人能用"。**

### 需要掌握
- 选**一个**方向深入（别贪多）：
  - Node 后端：hono 或 express——路由、中间件、请求校验、统一错误格式、部署
  - 前端：React + Vite——组件、状态、请求、构建产物
  - CLI / 库：commander 参数解析、tsup 构建、发布流程
- 分层架构：路由 / 服务 / 数据层分开，逻辑不糊在入口文件里
- 配置管理：环境变量 + 启动时校验，配置不硬编码
- 构建与打包：dev 和 build 的区别、产物怎么跑
- 统一的错误处理与日志策略，而不是到处 `console.log` + 复制粘贴 try/catch
- git 分支与提交习惯；README 写给用户看，不是写给自己看
- 完整部署上线一次：内网服务器、个人 VPS、云平台都算

### 常见错误
- 憋大招：三个月闷头写，没有一周是"能跑的"，最后烂尾
- 功能无边界：什么都想做，每个都是半成品
- 错误处理和日志到处复制粘贴，出了问题没法定位
- 跟着过时视频学，版本对不上、API 已废弃，也不去看官方文档
- 写代码都会，构建打包部署从没练过——最后一步永远"回头再说"，然后没有回头

### 练习（毕业项目，代码放 `05_毕业项目/`，选一个完整交付）
- [ ] 短链接服务（后端方向）：REST API + 存储 + 校验 + 统一错误格式 + 部署
- [ ] 记账 / 习惯打卡应用（前端方向）：React + Vite + 本地存储或简单后端
- [ ] 或直接把 AI_agent 的毕业项目用 TypeScript 交付——两门课合并毕业
- [ ] 硬性要求：README 讲清架构与运行方式、有测试、错误处理完整、构建并部署过至少一次

### 毕业标准（"能独立做项目"的定义）
- [ ] 从需求分析到部署上线全流程独立完成，技术选型说得出理由（为什么用它、不用它会怎样）
- [ ] 出问题能自己定位：看报错、打断点、查日志，不靠猜
- [ ] 能向别人讲清项目的能力边界：它不能做什么、什么时候会坏
- [ ] 有至少 1 个完整交付物：别人照着 README 能跑起来

## 路线设计说明

- 等级 1–4 一直用 `npx tsx` 直跑，不碰构建：先专注语言本身，构建和打包放到等级 5 才学，避免第一天就被工具链劝退
- zod 放等级 3 而不是更早：先在等级 2 手写类型守卫理解原理，再用工具提效——知道 zod 替你做了什么
- 测试放等级 4：等级 1–3 的项目小，肉眼能验；大到"重构会改坏"的规模，测试的价值才真正显出来
- 每级练习刻意衔接 AI_agent 课程：等级 3 的 zod 练习、等级 5 的合并毕业，TS 学完那边正好用上
- 每一级的晋级标准都是"能做到什么"，不是"看过什么"——卡在某一级，比带着窟窿往前走快
